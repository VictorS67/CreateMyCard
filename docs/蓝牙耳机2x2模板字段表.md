# 蓝牙耳机 2×2 模板字段表

基线：`VictorS67/CreateMyCard` 的 `jiakai0917-main-fix-new`，提交 `d9c5ca30`，
在此基础上兼容耳机 2×2 改进并新增 EarbudPairHero。按正式模板声明与 `.cardtpl` 核对，
不包含 2×4 专用宽版模板及 Support 模板；同时支持多种尺寸的模板在此仅列 2×2 字段。

## 全部 Full、Hero、Compact 模板

共 **13 个：Full 3 个、Hero 7 个、Compact 3 个**。
全部通过 `GetEarphoneInfo` 获取数据，调用入参为 `{}`，数据写入根为 `/data/earphone`。
下表字段是相对该根的路径。必需字段合并正式声明的主数据和次要数据；次要数据不等于可选数据。
可选字段仅表示模板能够展示，不能据此补充用户未要求的展示内容。
素材参数中的 `?` 表示可选，素材来自当前批准的素材候选，不是耳机查询参数。

| 类型 | 模板 ID | 必需数据字段 | 可选数据字段 | 素材参数（`?` 为可选） |
| --- | --- | --- | --- | --- |
| Full | `BluetoothDeviceOverviewEarbudsFull@1` | `/leftBatteryLevel`、`/rightBatteryLevel` | `/leftChargingStatusDesc`、`/rightChargingStatusDesc` | `leftEarIcon?: asset, rightEarIcon?: asset` |
| Full | `BluetoothDeviceOverviewEarbudPairFull@1` | `/isConnected`、`/earphoneName`、`/batteryLevel`、`/leftBatteryLevel`、`/rightBatteryLevel` | 无 | `caseIcon?: asset, leftEarIcon?: asset, rightEarIcon?: asset` |
| Hero | `BluetoothDeviceOverviewHero@1` | `/isConnected`、`/earphoneName` | `/leftBatteryLevel`、`/rightBatteryLevel` | `leftEarIcon?: asset, rightEarIcon?: asset` |
| Hero | `BluetoothDeviceOverviewEarbudPairHero@1` | `/earphoneName`、`/leftBatteryLevel`、`/rightBatteryLevel` | 无 | `leftEarIcon?: asset, rightEarIcon?: asset` |
| Hero | `BluetoothDeviceOverviewEarphoneCaseHero@1` | `/batteryLevel`、`/chargingStatusDesc` | 无 | `caseIcon?: asset` |
| Hero | `BluetoothDeviceOverviewEarphoneHero@1` | `/earphoneName`、`/batteryLevel` | 无 | `earphoneIcon?: asset` |
| Compact | `BluetoothDeviceOverviewEarbudPairCompact@1` | `/earphoneName`、`/leftBatteryLevel`、`/rightBatteryLevel` | 无 | `leftEarIcon?: asset, rightEarIcon?: asset` |
| Compact | `BluetoothDeviceOverviewEarphoneCaseCompact@1` | `/batteryLevel`、`/chargingStatusDesc` | 无 | `caseIcon?: asset` |

## 字段含义

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `/earphoneName` | string | 耳机名称；契约约定未连接时返回“未连接耳机” |
| `/isConnected` | boolean | 是否已连接耳机 |
| `/batteryLevel` | integer | 耳机盒或整体电量，百分比数值，不含百分号 |
| `/chargingStatusDesc` | string | 耳机盒或整体充电状态 |
| `/leftBatteryLevel` | integer | 左耳电量，百分比数值 |
| `/rightBatteryLevel` | integer | 右耳电量，百分比数值 |
| `/leftChargingStatusDesc` | string | 左耳充电状态 |
| `/rightChargingStatusDesc` | string | 右耳充电状态 |
| `/updatedAt` | string | 数据更新时间 |

## 检索与动作边界

- 字段覆盖和最终布局可用性分开判断。2×2 单业务常规无动作路径要求 Full；
  单动作可用 Hero 配合独立按钮；双动作可用 Compact 配合两个按钮。
  实际结果还受候选动作、素材、主题、模板启用状态及规划器约束影响。
- 上表业务模板不把“蓝牙设置”写死为动作；动作由布局按已选合法事件组合。
  耳机 2×2 单业务允许专用回退：无动作时优先可用 Full；Full 不适用且 Hero 可用时，
  可以补充候选中已有的蓝牙设置动作。用户明确不要按钮或跳转时禁止补充；其它业务不适用。
  Full/Hero 无适用方案后可继续判断 Compact；保留已选动作，缺一个先补蓝牙设置，
  蓝牙设置已选或不在候选时按需求相关性选择其它候选；缺两个按该优先级选两个不同动作，不固定第二项。
  所需动作均须存在于输入候选，
  缺候选时不补齐、不伪造。仅候选中存在不算已选，用户明确禁止按钮/跳转时同样禁止自动补充。
- “耳机名称＋耳机盒电量”有 EarphoneHero / EarphoneCompact 数据模板，
  但此基线没有只依赖这两个字段的 Full 模板；满足上述耳机专用条件时可回退 Hero 加蓝牙设置按钮。
- “耳机名称＋耳机盒电量＋耳机盒充电状态”没有一个上表模板能同时覆盖。
  用户明确要求三项时不能丢掉充电状态，用户只要求两项时也不能补上充电状态。
- “耳机盒电量＋耳机盒充电状态”对应 EarphoneCaseHero / EarphoneCaseCompact。

MusicFull 等新增 Full 同样参与无动作优先判断，是否可用以本轮启用模板及依赖是否齐全为准。
